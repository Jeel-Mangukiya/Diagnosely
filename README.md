# Diagnosely - Your AI-Powered Medical Assistant

Diagnosely is a modern web application that helps users understand their medical documents through AI-powered analysis and provides personalized healthcare guidance.

## 🌟 Features

### 1. Smart Document Analysis
- Upload and analyze medical documents (receipts, reports, prescriptions)
- Supports multiple file formats:
  - Images (JPG, PNG, TIFF, BMP)
  - PDF documents
- AI-powered text extraction and analysis
- Comprehensive analysis including:
  - Document summary and overview
  - Key medical findings
  - Medical terminology explanations
  - Medication analysis
  - Diagnoses and recommendations
  - Follow-up suggestions
  - Important warnings and alerts

### 2. AI Medical Chat
- Interactive chat interface for medical queries
- Personalized health recommendations
- Medical terminology explanations
- Contextual health information
- Secure conversation history

### 3. User Dashboard
- Overview of analyzed documents
- Recent activity tracking
- Document analysis history
- Quick access to AI chat
- Statistics and insights

### 4. Security Features
- Secure user authentication
- End-to-end encryption
- Protected medical data storage
- Role-based access control
- Privacy-focused design

## 🚀 Technology Stack

### Frontend
- React.js with TypeScript
- React Router for navigation
- Modern UI components with shadcn/ui
- Responsive design
- Real-time updates

### Backend
- Node.js/Express
- Supabase for database and authentication
- OpenRouter AI integration
- Tesseract.js for OCR
- PDF processing capabilities

### Storage & Database
- Supabase PostgreSQL database
- Secure file storage
- Real-time data synchronization

## 💻 Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/diagnosely.git
cd diagnosely
```

2. Install dependencies:
```bash
npm install
```

3. Set up environment variables:
Create a `.env` file with the following:
```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
VITE_OPENROUTER_API_KEY=your_openrouter_api_key
VITE_SITE_URL=your_site_url
```

4. Start the development server:
```bash
npm run dev
```
